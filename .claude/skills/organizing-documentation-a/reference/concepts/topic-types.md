# Topic types

Scope: the information-structure dimension — the typed shapes a source-of-truth topic can take. Definitional; the authoring actions live in the Principle 2 leaves.

- **Concept / explanation** — a mental model and the purpose behind it. Author with `reference/principles/02-typed-source-of-truth-topics/concept-pages.md`.
- **Task / how-to** — an action with an end state and verification. Author with `reference/principles/02-typed-source-of-truth-topics/task-pages.md`.
- **Reference** — precise, complete-in-scope lookup data. Author with `reference/principles/02-typed-source-of-truth-topics/reference-pages.md`.
- **Troubleshooting** — symptom → diagnosis → fix. Author with `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **Glossary** — a preferred term with its definition, synonyms, and scope. The corpus's own glossary is `glossary.md`; maintain vocabulary with `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.

Topic type is distinct from documentation mode and page genre — `design-dimensions.md`. Decide which topics deserve their own page in `reference/principles/02-typed-source-of-truth-topics/topic-identity.md`.
