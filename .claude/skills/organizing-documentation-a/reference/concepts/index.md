# Concepts

Scope: orientation hub for `reference/concepts/` — the framework's conceptual model: four design dimensions, documentation modes, glossary, metadata model, page genres, and topic types. Pure routing; each concept is defined in its owning file below.

## What is here

This directory holds the **definitional** layer — the concepts you look up to understand a distinction, not the how-to. The actions that apply these concepts live in the principles (`reference/principles/`); the workflow lives in `reference/procedure.md`.

## Start here

- **You must type a page along the four independent dimensions** (mode / topic type / genre / metadata): `design-dimensions.md` — the entry point to the conceptual model.
- **You need to settle a foundational distinction** (layered source of truth, stable identifier, agents as readers): `reference/foundations.md` — the framework's base layer, one directory up.
