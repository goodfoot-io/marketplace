# Documentation modes

Scope: the reader-intent dimension (Diátaxis) — learning, doing, looking up, understanding — and how each maps to a repo artifact. Definitional; the action of typing a page lives in `reference/principles/02-typed-source-of-truth-topics/modes-and-genres.md`.

- **Learning** (tutorial): a guided experience that builds understanding. In a repo this is usually served by the code, inline docs, and package READMEs next to what is learned — rarely a standalone page.
- **Understanding** (explanation): why something works the way it does. → an architecture wiki page (source-anchored synthesis), `reference/tools/wiki.md`.
- **Doing** (how-to): accomplish a specific goal. → a task script or guide, `reference/principles/02-typed-source-of-truth-topics/task-pages.md`.
- **Looking up** (reference): a technical description to consult and leave. → generated docs, a schema, a config doc, `reference/principles/02-typed-source-of-truth-topics/reference-pages.md`.

A reader consulting reference is interrupted by rationale; a reader seeking understanding is derailed by step-by-step instructions. **Do not mix modes in one page** — the modes go stale at different rates (`reference/tools/wiki.md` mode separation). Mode is one of four dimensions — `design-dimensions.md`.
