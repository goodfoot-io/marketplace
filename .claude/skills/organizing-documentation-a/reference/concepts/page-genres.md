# Page genres

Scope: the use dimension — the recognizable genres a page can take and what each is optimized for. The genre catalog (reference data); pick a genre when typing a page in `reference/principles/02-typed-source-of-truth-topics/modes-and-genres.md`. Genre is distinct from mode and topic type — `design-dimensions.md`.

| Genre | Optimize for | Author / owner |
|---|---|---|
| Concept / explanation | mental model, purpose, examples, prerequisites | `reference/principles/02-typed-source-of-truth-topics/concept-pages.md` |
| How-to / task | steps, prerequisites, outcomes, permissions, verification | `reference/principles/02-typed-source-of-truth-topics/task-pages.md` |
| Reference | precise lookup, structured data, completeness in scope, versioning | `reference/principles/02-typed-source-of-truth-topics/reference-pages.md` |
| Troubleshooting | symptoms, diagnosis, causes, fixes, evidence, escalation | `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md` |
| Runbook | time pressure, safety, rollback, verification, handoff | `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md` |
| Decision record (ADR) | context, options, decision, consequences, date, link to implementation | `reference/foundations.md` decision-history layer |
| Changelog | chronology, affected scope, versions, links to changed docs | `reference/foundations.md` decision-history layer |
| Glossary | preferred term, definition, synonyms, scope, disambiguation | `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md` |
| Hub | orientation, scope, routing, link quality | `reference/principles/03-hubs-orientation-and-routing/index.md` |
| Architecture overview | system boundaries, relationships, conceptual map, links to components | `reference/principles/02-typed-source-of-truth-topics/concept-pages.md` |
| Onboarding | sequenced path through prerequisites, each destination self-contained | `reference/principles/07-nonlinear-information-seeking/journeys.md` |
| Policy | authority, applicability, requirements, exceptions, evidence | `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md` |
| Checklist | completion, order, ownership, confirmation, reviewability | `reference/principles/02-typed-source-of-truth-topics/task-pages.md` |
| Migration guide | before/after states, steps, risks, dependencies, rollback | `reference/principles/02-typed-source-of-truth-topics/task-pages.md` |

**Historical genres.** A decision record, a changelog, or a captured plan or spike is correct as a record of its moment. When superseded, mark it historical — a status, a date, a scope note, and a replacement link — and preserve the content; do not rewrite it to match the current state (`reference/principles/02-typed-source-of-truth-topics/canonicality.md`).
