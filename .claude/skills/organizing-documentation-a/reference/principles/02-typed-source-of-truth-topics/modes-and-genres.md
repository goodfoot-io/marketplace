# Modes and genres

Scope: type a page along the four design dimensions and pick its genre; split pages that mix modes. Owns the typing action for Principle 2. The dimensions are defined in `reference/concepts/design-dimensions.md` and the genre catalog in `reference/concepts/page-genres.md`.

## Diagnose and act

- **Determine the documentation mode**: is the reader learning, doing, looking up, or understanding? Choose the matching mode — `reference/concepts/documentation-modes.md`.
- **A page mixes modes** (concept + task + reference in one README): separate the intents structurally; split into separate files only when the combined page weakens findability, usability, ownership, or maintainability. Use the `wiki` tool's mode separation — H2 per mode for a small component, separate files for a large one (`reference/tools/wiki.md`).
- **Pick the page genre** from the catalog and optimize the page for that genre's job — `reference/concepts/page-genres.md`.
- **Decide whether the topic deserves its own page at all**: `topic-identity.md`.
