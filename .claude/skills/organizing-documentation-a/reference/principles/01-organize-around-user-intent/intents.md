# Intents

Scope: match each arrival to what the reader is trying to do and route it to the right topic type. Owns the intent→genre mapping for Principle 1.

## Diagnostics → actions

Determine the dominant intent, then route:

- **Learn a concept**: route to a concept/explanation page — `reference/principles/02-typed-source-of-truth-topics/concept-pages.md`.
- **Complete a task**: route to a how-to with prerequisites and verification — `reference/principles/02-typed-source-of-truth-topics/task-pages.md`.
- **Debug a problem**: route to a symptom-led troubleshooting page — `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **Operate under pressure**: route to a concise runbook with diagnosis, safe actions, rollback, escalation — `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **Make a decision or compare alternatives**: provide criteria, tradeoffs, and "choose this when" guidance; link the decision record — `reference/foundations.md` decision-history layer, `reference/principles/06-information-scent/disambiguation.md`.
- **Verify a detail**: make the reference page fast to reach and precise within its scope — `reference/principles/02-typed-source-of-truth-topics/reference-pages.md`.
- **Understand why something is designed this way**: link current docs to rationale in the ADR/commit/PR — `reference/foundations.md`.
- **Onboard**: build a progressive path from concepts to tasks, each destination self-contained — `reference/principles/07-nonlinear-information-seeking/journeys.md`.
- **Recover from a failure**: prioritize diagnosis, rollback, known-good restoration, escalation thresholds — `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **Answer a compliance, security, or audit question**: create an evidence page with owner, scope, applicability, version — `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md`.
- **Hand off responsibility**: give owner, dependency, state, and next-action context — `reference/principles/05-controlled-vocabulary-and-metadata/entities.md`.

Make the common intents the backbone of navigation (`reference/principles/03-hubs-orientation-and-routing/orientation.md`); serve secondary intents through alternate paths (`reference/principles/04-multiple-paths/index.md`).
