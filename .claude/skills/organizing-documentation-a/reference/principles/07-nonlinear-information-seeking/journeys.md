# Journeys

Scope: model the common information-seeking journeys as paths through hubs, topics, search, and external entry points. Owns journey modeling for Principle 7.

## Diagnostics → actions

- **Name the common journeys** and model each as a path through hubs, topics, search, cross-links, and external entry points — `reference/principles/03-hubs-orientation-and-routing/index.md`.
- **A beginner journey**: build progressive learning and onboarding paths, sequencing concepts, tasks, and practice checkpoints, each destination self-contained.
- **An expert journey**: create shortcuts to reference and runbooks — `reference/principles/06-information-scent/cost-of-click.md`.
- **A debugging journey**: build symptom-to-cause-to-fix chains — `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **An incident journey**: build fast recovery paths with escalation.
- **A design-decision journey**: link current state to alternatives and rationale — `reference/foundations.md` decision-history layer.
- **A compliance-review journey**: build evidence trails and policy mappings — `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md`.
- **A migration journey**: give before/after states, steps, risks, dependencies, and rollback — `reference/principles/02-typed-source-of-truth-topics/task-pages.md`.
- **A customer-support journey**: link customer language to internal source-of-truth topics — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
- **A direct-arrival journey**: ensure each page explains context, scope, and next steps without assuming prior reading — `progressive-disclosure.md`.
