# Progressive disclosure

Scope: order each page so the highest-intent answer is first and depth is linked or below. Owns disclosure ordering for Principle 7.

## In the repo

Lead a README or page with the answer and link the depth rather than inlining it; linking a stable source-of-truth topic beats duplicating it, especially when ownership or freshness differs (`reference/principles/02-typed-source-of-truth-topics/topic-identity.md`, `reference/foundations.md`).

## Diagnostics → actions

- **The highest-intent answer is not first**: move it to the top; push detail below the basic path or into a linked reference.
- **Detail overwhelms beginners**: move it below the basic path; **detail experts need is buried**: promote it into a reference section or a quick link — `reference/principles/06-information-scent/cost-of-click.md`.
- **One page serves both beginners and experts**: add dual paths or role-based sections, and split "quick fix" from "deep explanation".
- **A page is dense before it is useful**: add a summary or quick answer before full details, a diagram before prose where relationships matter, and examples before exhaustive reference.
- **Detail affects safety or correctness**: keep warnings, prerequisites, and applicability constraints visible before action — `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md`.
