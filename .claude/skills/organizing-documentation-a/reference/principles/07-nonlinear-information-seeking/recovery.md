# Recovery

Scope: give lost readers and dead-ended tasks a way back — overview, related, next-step, and escalation links. Owns recovery paths for Principle 7.

## Diagnostics → actions

- **Readers get lost**: add clearer labels, local navigation, and back-to-hub or back-to-overview links — `reference/principles/06-information-scent/index.md`.
- **Readers reach a dead end**: add related, next-step, and back-to-hub links — `reference/principles/04-multiple-paths/orphans-and-dead-ends.md`.
- **A concept or reference page ends without a next move**: add related-task links; a task page, add common-problems and underlying-concept links — `reference/principles/04-multiple-paths/cross-linking.md`.
- **A reader needs the exact facts or the rationale from here**: add reference links near values and decision-history links near rationale — `reference/foundations.md` decision-history layer.
- **A reader may need to escalate**: add escalation thresholds and owners — `reference/principles/02-typed-source-of-truth-topics/troubleshooting-and-runbooks.md`.
- **Wrong turns are common here**: add a "you may be looking for…" disambiguation note — `reference/principles/06-information-scent/disambiguation.md`.
- **A reader arrived via an obsolete term**: add a redirect via a link, a replacement link, and an old/new terminology note — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
