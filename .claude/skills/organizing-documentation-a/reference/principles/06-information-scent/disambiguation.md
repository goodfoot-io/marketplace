# Disambiguation

Scope: separate easily-confused pages, concepts, and names with comparison notes, qualifiers, and "not X" notes. Owns disambiguation for Principle 6.

## Diagnostics → actions

- **Two pages or concepts are easy to confuse**: add comparison notes, cross-links, and a "not the same as" note near the confusing term or link — `reference/principles/02-typed-source-of-truth-topics/concept-pages.md`.
- **A name is overloaded**: qualify it by domain, system, product, or context — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
- **Two tasks sound similar but differ in risk**: add warnings and decision guidance.
- **Reference pages share similar titles**: rename or namespace them — `titles.md`.
- **Alternatives share many attributes**: use a comparison table so the choice is clear.
- **An old, renamed, or informal term needs handling**: redirect it with a link only when the destination is the correct replacement; route a wrong or ambiguous term through a disambiguation note — `reference/principles/02-typed-source-of-truth-topics/canonicality.md`.
- **A term needs defining**: define it at first use and in the glossary — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
- **An alias spans domains**: scope it to the domain where the equivalence is valid — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
