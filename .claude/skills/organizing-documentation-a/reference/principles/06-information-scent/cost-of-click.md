# Cost of click

Scope: shorten the path to high-value, high-risk, and emergency content; remove low-value hops. Owns navigation depth for Principle 6.

## In the repo

Directory depth is click cost. A hot file — one that changes often, by `git log` frequency (`reference/tools/git-history.md`) — buried deep earns a shortcut link from a top hub or the root `AGENTS.md`/`CLAUDE.md`.

## Diagnostics → actions

- **High-value content takes many hops**: shorten the path; bypass generic hubs with direct links — `reference/principles/03-hubs-orientation-and-routing/link-selection.md`.
- **An intermediate hub adds no value**: collapse or remove that navigation layer — `reference/principles/03-hubs-orientation-and-routing/hub-necessity.md`.
- **Too many links compete for attention**: prune and group them around intent — `reference/principles/03-hubs-orientation-and-routing/link-selection.md`.
- **The most common path is not the shortest**: reorder navigation around frequency and value — `reference/principles/01-organize-around-user-intent/prioritization.md`.
- **Emergency or incident paths are not short**: create direct incident shortcuts.
- **Task prerequisites or risk cues are not visible before the click**: surface them before step one and before risky links — `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md`.
- **A low-frequency but high-consequence path is hidden**: promote safety, compliance, and incident-critical links even if they are not common — `reference/principles/01-organize-around-user-intent/prioritization.md`.
