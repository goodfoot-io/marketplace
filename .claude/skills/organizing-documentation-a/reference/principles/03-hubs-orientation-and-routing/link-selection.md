# Link selection

Scope: choose which links belong on a hub, group them, and cue risk before the click. Owns hub link curation for Principle 3.

## Diagnostics → actions

- **Include only links that serve the hub's stated scope**; move too-detailed links down to lower-level pages.
- **High-intent or source-of-truth paths are missing**: add them — `reference/principles/02-typed-source-of-truth-topics/topic-identity.md`.
- **Links are redundant**: remove duplicates or merge the link groups.
- **Links are stale or point at non-source-of-truth pages**: update, redirect, or replace them with the source-of-truth or replacement destination — `reference/principles/02-typed-source-of-truth-topics/canonicality.md`.
- **A link's destination is not obvious**: add a short description before the click — `reference/principles/06-information-scent/link-labels.md`.
- **Links should be grouped**: cluster them by intent, lifecycle stage, role, system, or failure mode — `reference/principles/04-multiple-paths/facets.md`.
- **Some links are start-here, others are related**: elevate the former, demote the latter, remove noise — `reference/principles/06-information-scent/cost-of-click.md`.
- **A destination carries risk, permission, version, or environment constraints**: add those cues before the reader commits — `reference/principles/06-information-scent/link-labels.md`, `reference/principles/05-controlled-vocabulary-and-metadata/metadata-fields.md`.
