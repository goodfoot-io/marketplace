# Orientation

Scope: give the reader "where am I, what to read first, what to skip" on every hub. Owns hub orientation for Principle 3.

## Diagnostics → actions

- **Explain where the reader is and when to use the hub** ("use this when").
- **Elevate the common starting points** as explicit "start here" links — `link-selection.md`.
- **Separate the paths**: beginner from expert, normal operation from emergency, learning from action, current systems from legacy.
- **There are common confusions**: add "not the same as" notes — `reference/principles/06-information-scent/disambiguation.md`.
- **Tell readers what to read first and what they can skip** to reduce cognitive load.
- **Readers arrive directly from search**: make the hub's purpose and scope clear without assuming prior navigation — `reference/principles/07-nonlinear-information-seeking/index.md`.
