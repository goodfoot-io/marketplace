# First-click (repo proxy)

Scope: check the first hop — can a reader predict the right destination from a hub link or directory name. Owns the first-click check for Principle 8; this is the hub spot-check in Step 9 of `reference/procedure.md`.

## The repo proxy

For each common task, define the expected first file or directory a reader should open, then spot-check whether the hub link or directory name makes that first choice predictable without opening anything.

## Diagnostics → actions

- **Define the intended first click per common task** as the testable target — `reference/principles/01-organize-around-user-intent/intents.md`.
- **A wrong first click is common**: identify the misleading label, category, or competing path.
- **It is caused by a bad label**: rewrite for scent — `reference/principles/06-information-scent/link-labels.md`, `reference/principles/06-information-scent/titles.md`.
- **It is caused by bad grouping**: move the item to the expected group — `card-sorting.md`, `reference/principles/04-multiple-paths/facets.md`.
- **It is caused by missing synonyms**: add aliases — `reference/principles/05-controlled-vocabulary-and-metadata/vocabulary.md`.
- **It is caused by an ambiguous hub**: rewrite the hub orientation and link groups — `reference/principles/03-hubs-orientation-and-routing/orientation.md`, `reference/principles/03-hubs-orientation-and-routing/link-selection.md`.
- **A correct first click still leads to failure**: inspect the destination's opening, instructions, and onward links — `reference/principles/06-information-scent/summaries-and-previews.md`, `reference/principles/07-nonlinear-information-seeking/cross-reference.md`.
- **Treat the first-click rate as a signal, not a guarantee** of task success.
