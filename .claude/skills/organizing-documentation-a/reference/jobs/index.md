# Jobs

Scope: choose your job — the reader-intent entry into the skill (Principle 1). Three jobs share one loop (`reference/procedure.md`) with different emphasis: creating establishes conventions and a root hub early; updating audits first and changes only what a failure signal justifies; organizing runs drift detection and governance on a cadence.

- **You are standing up documentation from little**: read `creating.md` — establish conventions and a root hub first, with creation-phase emphasis.
- **A change just landed and the docs must catch up**: read `updating.md` — audit first; change only what a failure signal justifies.
- **You are maintaining an existing corpus over time**: read `organizing.md` — drift detection and governance on a cadence.

If you arrived with a symptom rather than a job, start from `reference/diagnostics.md`.
