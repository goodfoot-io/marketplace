# Measurement

Measure the stage the asset targets — the most common error is measuring a different stage and calling it success. Intent signals (clicks, signups, survey enthusiasm) are evidence of intent, not of durable adoption.

| Stage | Measure | Not |
|---|---|---|
| Attention | recall, consideration | conversions |
| Comprehension | mental-model accuracy: can the reader state what it does and where it fails? | time-on-page, engagement |
| Evaluation | preference vs. the reader's current workflow; pilot on their own tasks | benchmark deltas |
| Trust | appropriate reliance: override frequency, false accepts/rejects, post-error recovery | maximum reliance / raw acceptance rate |
| Trial | first successful use on own material; time-to-first-success | signups |
| Retention | retained weekly use, confirmed value, workflow dependency, abandonment reasons | renewal-intent surveys |

- Measure end-to-end, not first-draft: completion time including review and verification, edit distance, merge latency. A tool can speed drafts and slow completion.
- Segment by expertise and task type; averages hide reversals (experienced users on familiar work can be slowed while others gain).
- Never report another context's uplift as a projected result — measure in the customer's own workflow.
