# Interactive demo / trial experience

- Make interaction pause the flow. Interaction that halts playback while the user acts improves outcomes (g≈0.52, from educational-video interaction research; mechanisms transfer); interaction layered over continuous playback splits attention and can perform worse than passive video.
- Optimize perceived responsiveness, not widget count — felt interactivity predicts engagement; feature count does not.
- Get the user's own material in fast. Hands-on direct experience builds attitudes that are stronger and far more behavior-predictive than passive exposure — this is why the demo (not the video) is the right asset for the trust and trial stages.
- Never claim "demos convert better" — no marketing-specific demo-vs-video test exists. Build for attitude durability; measure conversion.
