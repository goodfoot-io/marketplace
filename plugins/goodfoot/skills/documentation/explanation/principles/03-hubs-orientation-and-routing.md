# Principle 3 — Hubs as orientation and routing layers

Scope: why hubs orient and route but never own the facts their links point to. Explanation mode.

A hub's value is navigation: it tells a reader where they are, which path to choose, and why a link matters before the click. A hub that duplicates volatile facts goes stale and competes with the page that owns them.

## In a repo

The root `README` is the product hub; `AGENTS.md`/`CLAUDE.md` are agent hubs; a `README` at each module boundary is a local hub. The concerns: **necessity** (a density threshold for adding one), **scope**, **orientation**, **link selection**, **content**, and **anti-duplication** (the hub's authority is routing, not the facts). This is "generate, don't duplicate" applied to navigation.
