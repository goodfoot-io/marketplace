# Cross-media campaigns

Reinforcing a message in a second medium beats more repetition in one medium — done right:

- Re-execute, don't re-skin: keep the core claim constant, make each medium's creative visibly different. Identical creative across media improves evaluation but *hurts* memory; varied executions encode distinctly.
- Cross-media repetition beats same-medium repetition at equal frequency (credibility, attitude, intent).
- Budget the weaker medium generously — synergy models show its marginal contribution is undervalued by single-medium thinking.
- Cap frequency per audience member: exposure–liking is an inverted U. When reach starts repeating, vary the execution instead of adding exposures.
