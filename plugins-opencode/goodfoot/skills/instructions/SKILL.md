# Write for OpenCode
OpenCode is the audience. Anything that you infer, OpenCode will infer. 

Use as few tokens as possible without losing clarity or meaning.

# Reduce token count
Try to remove at least 1.2 tokens for every 1 token you add to pre-existing instructions.

# Information must be actionable
Ask: "Why does OpenCode need to know this?" 

The cheapest tokens to cut are rationale asides explaining why a rule exists rather than just stating the rule.
